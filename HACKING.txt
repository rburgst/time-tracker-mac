Time Tracker development
========================

Requirements
------------

* macOS 12.0 or later
* Xcode with the macOS SDK and command-line tools

Build and run
-------------

Open `Time Tracker.xcodeproj`, select the `Time Tracker` scheme and `My Mac`
destination, then choose Product > Run.

For a command-line build from the repository root:

    xcodebuild -project "Time Tracker.xcodeproj" \
      -scheme "Time Tracker" \
      -configuration Debug \
      -destination 'platform=macOS' \
      -derivedDataPath build \
      build

The built application is at:

    build/Build/Products/Debug/Time Tracker.app

The old release packaging and publishing instructions have been retired. They
depended on PowerPC build settings, Google Code hosting, and credentials for
services that are no longer part of the supported development workflow.
